# Lingo Reader（プロトタイプ）

好きな文章を教科書にする語学学習アプリ。Vite + React。

## 起動
```bash
npm install
npm run dev    # スマホ実機で見る場合は表示される Network URL を開く
```

## 構成
- `src/screens/Home.jsx`   モード選択（ペースト / AI生成）
- `src/screens/Reader.jsx` リーディング＆スマート辞書（タップ・ハイライト・小窓・保存）
- `src/screens/Wordbook.jsx` 単語帳リスト
- `src/lib/tokenize.js`    Intl.Segmenter による分割（空白のない言語もOK）
- `src/lib/dictionary.js`  **モック辞書**。`lookupWord()` を AI/辞書API に差し替える
- `src/lib/storyAI.js`     **モックAI**。`generateStory()` を LLM API に差し替える
- `src/lib/storage.js`     単語帳の localStorage 保存（重複は言語+原形で除外）

## 操作仕様
- 単語タップ → ハイライト + 小窓（辞書にある熟語は最長一致で自動的にまとめてハイライト）
- 小窓タップ → 小窓だけ閉じる（ハイライトは残る）
- ハイライト済みを再タップ → 解除
- 右上「保存」→ ハイライト全件を単語帳へ一括保存

## v0.6 単語復習（エビングハウス）
- `src/lib/srs.js`：復習スケジュール（純粋関数）。保存=step0 → 20分 → 1時間 → 1日 → 1週間 → 1か月 → step5で習得済み。「忘れた」は step0 に戻り20分後
- 単語帳画面に「単語帳 / 復習」の切り替え。復習タブに本日の復習対象・今後の予定・スケジュール説明。言語タブで復習範囲も絞り込み
- `src/screens/Review.jsx`：フラッシュカード（表=単語+例文、裏=日本語の意味、タップでめくる）＋「覚えた/忘れた」
- ホームに「今日の復習」カード（対象枚数のバッジ付き）。対象数は30秒ごと・画面復帰時に更新
- 旧バージョンで保存した単語は、読み込み時に step0（保存から20分後）として自動で補完

## 本番化の際の差し替えポイント
`translateSentences` / `translateSelection` も同様に AI 翻訳へ差し替え可能です。
`lookupWord(text, lang, context)` の `context`（その単語を含む文）をAIに渡すと、
文脈に応じた意味・活用の判定ができます。熟語の範囲判定 `findRange()` も、
AIが返す範囲に差し替え可能です。

## v1.0
- 「文章をペーストして学ぶ」に文章の種類（その他／本／記事／歌詞）を追加
- 本: 白紙の本が開くアニメ → 見開きで題名・言語・総ページ数・1日の目標を入力 → ページがめくれて1ページ目 → 本文を貼り付け。1ページずつ登録して読み進め、進捗・今日の目標を表示
- ライブラリ（本棚）: 登録した本だけが背表紙で並び、進捗・読み終えた本・学んだページを表示
- 記事: トピック（選択／自由入力）＋タイトル。マイ教材はトピックごとにフォルダー表示
- 歌詞: アーティスト別フォルダー。登録済みアーティストを選んで曲を追加、または新規作成
- 本・記事トピック・アーティストはすべて localStorage 自動保存＆JSONバックアップ対象（lingo-reader:books:v1）

- 文章の種類に「長文問題」を追加。長文問題・その他は「既存ファイルを選ぶ／新規作成」。記事はトピック、歌詞はアーティスト、AI物語は「AI物語」のファイルへ自動で格納

## v1.4 通知機能
- ホーム上部の「今日のバナー」: 「今日復習する単語が◯件あります」＋「◯日連続学習中！🔥」。復習ボタン、🔔ボタン（期限があると赤い点）
- 🔔通知設定: 通知の許可、復習タイミングの通知（忘却曲線の期限が来た単語がある時）、毎日の学習リマインド（時刻を指定、既定 20:00）、テスト通知
- 連続学習日数: 復習に答える／単語を保存／文章・ページを登録した日を記録（端末ごと、バックアップ対象外: lingo-reader-study:v1。設定は lingo-reader-notify:v1）
- PWA化: manifest.webmanifest・アイコン・Service Worker（public/）。ホーム画面に追加するとアプリとして起動
- 通知の送り方: Service Worker の showNotification。アプリ表示中は画面内バナーで足りるので復習通知は出さず、復習通知は最短3時間おき、毎日通知は設定時刻から3時間以内に開かれ、かつ今日まだ学習していない場合のみ。Notification Triggers 対応ブラウザでは毎日の通知を事前予約
- 制約: サーバー無し構成のため、アプリを完全に終了している間の本物のWebプッシュ（VAPID＋プッシュサーバー）は未対応。通知は https または localhost で動作（iPhone はホーム画面に追加したアプリのみ）
